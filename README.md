# 局域网文件接收平台

一个轻量级的局域网文件接收服务：同一局域网内的电脑或手机，打开浏览器即可把文件发送到本机，无需安装任何客户端。

## 功能

- 网页拖拽 / 多选上传，带实时进度条
- 自动保存到本机 `uploads` 目录，同名文件自动加 `(1)`、`(2)` 不覆盖
- 支持中文文件名
- 可选访问码，防止局域网内无关人员上传
- 首页显示“最近接收”列表（文件名、大小、时间、来源 IP）
- 启动时打印局域网访问地址和手机扫码二维码

## 快速开始

1. 安装 Python 3.8+（安装时勾选 “Add Python to PATH”）。
2. 双击 `start.bat`（或命令行运行 `python server.py`）。
   首次运行会自动生成 `config.json`，并检查依赖（缺少时自动安装）。
3. 看到 “局域网文件接收平台已启动” 后，把提示的访问地址发给局域网内的同事：

   ```
   http://192.168.x.x:8000/
   ```

4. 对方浏览器打开该地址，把文件拖进页面即可。文件会保存在本项目的 `uploads` 文件夹里。

## 首次使用：开放防火墙

如果其他电脑打不开页面，通常是 Windows 防火墙拦截了入站连接。**右键** `open-firewall.bat`，选择 **“以管理员身份运行”**，即可为服务端口添加入站规则。

> 注意：本机和接收方必须在同一个局域网（同一路由器 / 同一 Wi-Fi）下。

## 配置文件（config.json）

首次运行后生成，可直接用记事本修改：

| 字段 | 说明 | 默认值 |
| --- | --- | --- |
| `port` | 服务端口，修改后需重启服务 | `8000` |
| `upload_dir` | 保存文件的目录 | `uploads` |
| `max_file_size_mb` | 单次上传总大小上限（MB），`0` 表示不限制 | `10240`（10GB） |
| `access_code` | 访问码，留空表示不启用；启用后上传必须填写 | `` |
| `recent_limit` | 页面“最近接收”最多显示条数 | `50` |

修改端口后，请重新运行 `open-firewall.bat` 开放新端口。

## 常用命令

```bat
python server.py            :: 启动服务
python server.py --open     :: 启动并自动打开浏览器
python server.py --port 9000 :: 临时改用 9000 端口
```

## 常见问题

**其他电脑无法访问页面？**
先确认对方与本机在同一局域网，再检查：
1. 是否已运行 `open-firewall.bat`（需管理员权限）；
2. 本机是否连接了多个网络（VPN、虚拟机网卡等），用 `ipconfig` 确认本机 IP；
3. 安全软件（360、腾讯管家等）是否拦截了 Python 进程。

**提示端口被占用？**
把 `config.json` 里的 `port` 改成其他数值（如 `9000`）后重启，并重新开放防火墙端口。

**手机上传？**
手机与电脑连同一 Wi-Fi，用相机扫描启动界面或网页上的二维码即可打开上传页面。

## 安全提示

本平台默认不设访问码，同一局域网内知道地址的人都可以上传文件。若在公共网络环境使用，请先在 `config.json` 中设置 `access_code`。
